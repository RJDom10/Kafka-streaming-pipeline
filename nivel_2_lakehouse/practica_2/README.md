# Laboratorio 2: Streaming Lakehouse en la Practica

Este laboratorio esta disenado para poner en practica los conceptos de una
Arquitectura Medallion usando Apache Kafka, PySpark, Apache Iceberg y Trino.

## Modulos

1. **[Teoria Profunda](./01_teoria_profunda_lakehouse.md):** Vision detallada del funcionamiento interno.
2. **[Guia Demostrativa](./02_guia_demostrativa_paso_a_paso.md):** Tutorial guiado para levantar la arquitectura y ejecutar los scripts.
3. **[Retos Practicos](./03_laboratorio_retos_practicos.md):** 4 desafios tecnicos para probar las capacidades de Iceberg y Trino.
4. **[Comandos Utiles](./04_scripts_y_comandos_utiles.md):** Referencia rapida de comandos Docker, Spark y Trino.

Asegurate de haber ejecutado la Guia Demostrativa antes de intentar los Retos Practicos, ya que estos ultimos dependen de que los datos esten cargados en las tres capas (Bronze, Silver, Gold).
